# Titanic Survival Prediction

This project is a Machine Learning project based on the famous Titanic dataset.  
The goal of the project is to predict whether a passenger survived or not using different machine learning algorithms.

## Project Overview

In this project, I:
- Cleaned and prepared the dataset
- Handled missing values
- Performed data analysis and visualization
- Selected important features
- Trained multiple machine learning models
- Compared model accuracy results

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Machine Learning Models

The following models were tested:
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Gaussian Naive Bayes

## Project Goal

The main objective of this project was to learn:
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Machine Learning basics
- Model evaluation and comparison

## Dataset

The dataset used in this project is the Titanic dataset from Kaggle.

## Results

Different machine learning models were compared based on training accuracy to find the best-performing model.
